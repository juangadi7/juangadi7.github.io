# juangadi7.github.io

Mi web de portfolio: **https://juangadi7.github.io**

- `/` — presentación, proyectos, cómo trabajo con IA y contacto.
- `/mareval/` — web de producto para **Mareval**, una relojera de lujo **ficticia**. El reloj de la portada está dibujado en SVG y marca la hora real del visitante; las fotos son de Unsplash.

HTML, CSS y JavaScript sin librerías ni proceso de build. Fuentes Hanken Grotesk y Bodoni Moda (SIL OFL), alojadas en `assets/fonts`.
